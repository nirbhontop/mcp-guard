# mcp-guard

Zero-dependency CLI security auditor for Model Context Protocol (MCP) server configurations, AI agent rule files (`CLAUDE.md`, `AGENTS.md`, `.cursorrules`), and local environment leaks.

## Quickstart

```bash
git clone https://github.com/nirbhontop/mcp-guard.git
cd mcp-guard
npm install
npm test
node dist/cli.js .
```
